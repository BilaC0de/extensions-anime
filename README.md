# Extensions Anime — BilaC0de

Dépôt de distribution des extensions Aniyomi/Anikku développées et maintenues personnellement.

## Ajouter le dépôt dans Aniyomi / Anikku

1. Ouvrir Aniyomi (ou Anikku) → **Paramètres** → **Sources** → **Dépôts d'extensions**
2. Ajouter l'URL suivante :

```
https://raw.githubusercontent.com/BilaC0de/extensions-anime/repo-anime/index.min.json
```

## Sources disponibles

Les extensions sont principalement orientées vers les sites de streaming d'anime francophones.

## Développement

Le code source des extensions se trouve dans le dépôt [animes-extensions-source](https://github.com/BilaC0de/animes-extensions-source).

Les extensions sont compilées et publiées automatiquement à chaque push sur la branche `dev`.
